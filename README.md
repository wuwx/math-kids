# 小学数学练习

一个为小学生设计的数学练习题生成工具，支持自动出题、自定义难度、一键打印。

**在线使用：<https://wuwx.github.io/math-kids/>**

## 功能特点

- 🎯 34 种练习类型：覆盖基础运算、小数分数、逻辑思维、应用题等 8 大分类
- ⚙️ 自定义参数：题目数量、数值范围、运算符选择
- 🖨️ 打印优化：每页自动重复页头，题目不会被截断
- 🌙 深色模式支持

## 练习分类

| 分类 | 说明 |
|------|------|
| 基础运算 | 加减法、进位借位、乘除法、竖式、估算、19×19 乘法等 |
| 小数分数 | 小数加减、同分母分数加减 |
| 数的认识 | 数位、奇偶数、因数与倍数 |
| 单位换算 | 时间计算、人民币换算、长度重量单位 |
| 图形几何 | 周长、面积、图形计数 |
| 逻辑思维 | 填空算式、比大小、找规律、24点、数独、火柴棒 |
| 应用题 | 购物分配、行程、植树、鸡兔同笼 |
| 速度训练 | 限时口算 |

## 技术栈

- [Nuxt 4](https://nuxt.com/)
- [Nuxt UI 4](https://ui.nuxt.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

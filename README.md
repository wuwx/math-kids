# 小学数学练习

一个为小学生设计的数学练习题生成工具，支持自动出题、自定义难度、一键打印。

## 功能特点

- 🎯 6 种练习类型：加减法、进位借位、乘除法、三数连算等
- ⚙️ 自定义参数：题目数量、数值范围、运算符选择
- 🖨️ 打印优化：每页自动重复页头，题目不会被截断
- 🌙 深色模式支持

## 练习类型

| 类型 | 说明 |
|------|------|
| 三位数加减法 | 100-999 范围内的加减法 |
| 进位借位练习 | 带进位的加法和借位的减法 |
| 乘除法练习 | 两位数乘除一位数 |
| 三数连算 | 三个三位数的连续加减运算 |
| 三数连算 II | 带括号的三数运算 |
| 综合练习 | 加减乘混合运算 |

## 技术栈

- [Nuxt 4](https://nuxt.com/)
- [Nuxt UI 4](https://ui.nuxt.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```
